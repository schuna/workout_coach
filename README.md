# 🏋️‍♂️ 웨이트 트레이닝 어시스턴트 (Workout Coach Web App)

대화형 웨이트 트레이닝 진행 가이드, 실시간 세트별 목표 표시, 절대 시간 기반 자동 휴식 카운트다운 타이머, 추정 1RM(1 Rep Max) 계산, 운동 빈도 잔디 캘린더 히트맵 대시보드, PWA(Progressive Web App) 오프라인 지원, 그리고 구글 스프레드시트([웨이트 트레이닝 운동 기록부](https://docs.google.com/spreadsheets/d/1s31Mysp47Xv43AR_hIThAppiHsoAJkvAw2cgy6CET5I/edit)) 양방향 연동 기능을 갖춘 모바일 최적화 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **PWA (Progressive Web App) 완전 지원**:
   - `manifest.json` 및 서비스 워커(`sw.js`)를 탑재하여 스마트폰 홈 화면에 '앱으로 설치(Standalone)' 지원
   - 브라우저 상/하단 주소창 없이 100% 네이티브 앱 풀스크린 환경 제공
   - 네트워크 연결이 불안정한 지하 헬스장에서도 오프라인 캐시를 통해 즉각 실행
2. **지난 기록 자동 표시 & 불러오기 (점진적 과부하 가이드)**:
   - 종목 선택 시 해당 종목의 가장 최근 수행 기록(날짜, 최고 무게, 세트 수, 총 볼륨)을 상단 배너로 즉시 안내
   - `[⚡ 불러오기]` 버튼 원터치로 지난 세션의 무게와 횟수를 현재 세트 계획으로 즉각 복사
3. **추정 1RM(1 Rep Max) 실시간 계산**:
   - Epley 공식($\text{1RM} = \text{Weight} \times (1 + \text{Reps} / 30)$) 기반의 실시간 1RM 추정
   - 세트 진행 중 목표 및 실제 수행치에 따른 1RM을 실시간 표시하며, 세션 완료 요약 및 히스토리 기록에 최고 1RM 기록 보관
4. **종목 선택 & 맞춤 휴식 설정**:
   - 벤치프레스, 스쿼트, 데드리프트, OHP, 바벨 로우, 풀업, 덤벨 컬, 펙 덱 플라이 등 8대 기본 종목 및 사용자 커스텀 종목 관리
   - 종목 특성에 맞춘 휴식 시간(30s, 45s, 60s, 90s, 120s, 180s) 퀵 프리셋 설정 지원
5. **세트 및 목표 수립 도구**:
   - 세트 수 조절(1~12세트), 세트별 목표 무게(kg)와 횟수(회) 간편 입력
   - 1세트 값 일괄 복사 및 피라미드 세트(+5kg / -2회) 자동 계산 도구 지원
6. **실시간 모바일 세트 가이드**:
   - **화면 꺼짐 방지(Screen Wake Lock API)** 적용으로 운동 중 화면 꺼짐 완벽 차단
   - 전체 운동 경과 시간(스톱워치), 현재 세트 번호(SET X / Y), 목표 무게/횟수 시인성 높은 대형 디스플레이
   - 실제 수행 무게/횟수 원터치(±2.5kg, ±1회) 미세 조정
7. **절대 시간 기반 휴식 카운트다운 타이머 루프**:
   - 모바일 브라우저 백그라운드 전환이나 화면 잠금 시에도 오차 없는 타임스탬프(`Date.now()`) 기반 정밀 타이머
   - 원형 SVG 프로그레스 링, 잔여 3초 카운트다운 비프음 및 0초 도달 시 3단 차임벨 사운드/진동 피드백
   - +15초, -15초, 즉시 다음 세트 스킵 지원
8. **분석형 대시보드 (Analytics Dashboard)**:
   - **운동 빈도 잔디 캘린더 (Activity Heatmap)**: 최근 10주간(70일)의 운동 여부 및 볼륨 강도를 색상 타일로 시각화 (연속 운동 Streak 트래킹)
   - **주간 볼륨 추이 바 차트**: 최근 4주간의 주차별 운동 볼륨(kg) 변화 비교
   - **부위별 운동 비중 게이지**: 가슴, 하체, 등, 어깨, 팔 훈련 밸런스 점검
   - **기간 필터(전체 / 최근 7일 / 이번 달)** 제공
9. **대용량 데이터 최적화 & 백업/복원**:
   - DOM 병목 방지를 위한 **히스토리 페이징(10건 단위 '더보기') 렌더링**
   - 브라우저 데이터 유실에 대비한 **원클릭 JSON 데이터 전체 백업 및 복원**
   - 구글 스프레드시트 양방향 동기화 (POST 자동 누적, GET 시트 기록 동기화) 및 CSV 다운로드, TSV 복사 지원
10. **연속 훈련 루틴 연계**:
    - 한 종목 종료 후 곧바로 `+ 다음 종목 이어서 하기`를 통해 일일 다종목 루틴을 매끄럽게 진행

## 🚀 GitHub Pages로 무료 호스팅하기
이 레포지토리는 GitHub Pages로 1분 만에 무료 배포할 수 있습니다:
1. GitHub에서 새 레포지토리(예: `workout-coach`) 생성 후 파일 업로드
2. 레포지토리의 **Settings** > **Pages** 이동
3. **Build and deployment** > Branch를 `main` (또는 `master`), 폴더를 `/ (root)`로 선택 후 **Save**
4. 생성된 `https://<깃허브아이디>.github.io/workout-coach/` 주소로 스마트폰이나 PC 어디서든 즉시 접속 가능!
5. 모바일 크롬/사파리에서 접속 후 **[홈 화면에 추가]** 또는 상단 **[📲 앱 설치]** 버튼을 누르면 독립된 네이티브 앱으로 사용 가능합니다.
