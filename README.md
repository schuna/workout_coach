# 🏋️‍♂️ 웨이트 트레이닝 어시스턴트 (Workout Coach Web App)

대화형 웨이트 트레이닝 진행 가이드, 실시간 세트별 목표 표시, 60초 자동 휴식 카운트다운 타이머, 그리고 구글 스프레드시트([웨이트 트레이닝 운동 기록부](https://docs.google.com/spreadsheets/d/1s31Mysp47Xv43AR_hIThAppiHsoAJkvAw2cgy6CET5I/edit)) 연동 기능을 갖춘 인터랙티브 웹 애플리케이션입니다.

## ✨ 주요 기능
1. **종목 선택**: 벤치프레스, 스쿼트, 데드리프트, OHP, 바벨 로우, 풀업, 덤벨 컬, **펙 덱 플라이** 등 8대 기본 종목 및 사용자 커스텀 종목 추가/관리
2. **세트 및 목표 수립**: 세트 수 조절, 세트별 목표 무게(kg)와 횟수(회) 간편 입력 및 피라미드/일괄 복사 툴 지원
3. **실시간 세트 가이드**: 전체 운동 경과 시간(스톱워치), 현재 세트 번호(SET X / Y), 목표 무게/횟수 시인성 높은 대형 디스플레이
4. **60초 휴식 타이머 루프**: 세트 완료 시 60초 카운트다운 원형 프로그레스 바 작동, 0초 도달 시 3단계 비프음 알림과 함께 다음 세트로 자동 전환
5. **기록 저장 및 구글 시트 연동**:
   - 브라우저 로컬 저장소(localStorage)에 자동 저장되어 날짜별 볼륨 및 세션 히스토리 열람 가능
   - 구글 스프레드시트 헤더 서식에 맞춘 원클릭 클립보드 복사(TSV) 및 CSV 내보내기 지원

## 🚀 GitHub Pages로 무료 호스팅하기
이 레포지토리는 단일 HTML 파일(`index.html`)로 구성되어 있어 GitHub Pages로 1분 만에 무료 배포할 수 있습니다:
1. GitHub에서 새 레포지토리(예: `workout-coach`) 생성 후 파일 업로드
2. 레포지토리의 **Settings** > **Pages** 이동
3. **Build and deployment** > Branch를 `main` (또는 `master`), 폴더를 `/ (root)`로 선택 후 **Save**
4. 생성된 `https://<깃허브아이디>.github.io/workout-coach/` 주소로 스마트폰이나 PC 어디서든 즉시 접속 가능!
